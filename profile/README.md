# DMDE - Look at a Damaged Volume Before You Write to It

## Read First

The first session should be a scan and a copy of files you recognize onto another disk. DMDE can show partitions that Windows no longer assigns a letter, and it can reconstruct a directory from what is left. Open a few recovered files before you celebrate a file count. A directory entry can exist while the clusters are already overwritten.

Do not initialize, format, or "repair" the source because another Windows dialog offered it. Those writes are the opposite of this tool's first job.

## Safe Order

| Step | Why |
|---|---|
| Stop using the source | More writes cover the files you want |
| Scan | See whether a partition or a file system is still described |
| Preview | Open a photo or a document from the result |
| Copy out | Destination is a different disk |
| Write to the source | Only if you already have a full copy and you know the partition edit |

## Steps

1. Attach the disk and do not let Windows format it.  
2. Select the physical disk and look for the lost volume.  
3. Scan if the volume is not obvious.  
4. Preview a handful of important files.  
5. Copy them to a different disk.  
6. Leave the source unchanged until those copies open.

## Fits

Your own disk that lost a partition or a file system, with another disk available for the copies. A poor fit for encrypted volumes whose key you do not have. DMDE does not bypass encryption. A poor fit for a drive that is clicking so badly it should be imaged by someone who will not power-cycle it all afternoon. A poor fit for "recover the password."

## Requirements

| Item | Expectation |
|---|---|
| Source | A disk you may read |
| Destination | Different media with room |
| OS | Windows the build supports |
| Patience | Scans of large disks take time |
| Writes | Deferred until copies exist |

## Fixes

The scan finds names and the preview is garbage. The file bodies are overwritten or the file system guess is wrong. Try another reconstruction only after you have saved what did preview.  
Windows insists on formatting. Cancel that dialog.  
The copy is slow and then the disk vanishes. Stop. More retries can make a failing drive worse.  
You recovered to the same disk. Move those files off before you scan again.  
A partition edit is tempting. Do it only on a disk you have already imaged elsewhere.

## Preview a File You Would Miss

A long list of recovered names is not a recovery. Open two or three files you actually need: a photo, a spreadsheet, a document. If they open, copy that set to another disk and stop touching the source. If they are garbage, the directory entries survived and the data did not, or the file system guess is wrong. Save what did preview before you try a different reconstruction.

Windows' format dialog is the hazard during the scan. Cancel it. Initializing the disk writes over the table you are trying to read. Encrypted volumes stay unreadable without the key. DMDE will not break that. A drive that disappears mid-scan should be left alone. More power cycles are not a strategy.

| Preview | Next |
|---|---|
| Files open | Copy them out and stop |
| Names only, garbage preview | Do not write to the source |
| Format prompt | Cancel |
| Disk vanishes | Stop the session |

Copy the files that opened onto a different disk before you try a second scan. Another reconstruction can be useful, and it should not be the first time those good files leave the source.
